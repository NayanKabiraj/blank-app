# Saved Shorts

Every run of the daily workflow saves its videos here, whether or not they were uploaded
to YouTube: `videos/<date>/en.mp4` and `hi.mp4`, with the title, description and tags in
`<lang>_youtube.txt`. The workflow commits them to the branch it ran on.

Each video is about 10-15 MB, so delete old date folders now and then to keep the repo small.
